# Proyecto

## Nombre

ASD_II

## Materia

Analisis de Series de Tiempo 2 - FIUBA - Maestria en Inteligencia Artificial.

## Objetivo del repositorio

Centralizar materiales de clase, notebooks de practica, tareas y entregas de la materia.

El proyecto se trabajara principalmente con Python desarrollando notebooks compatibles con Google Colab.

## Estructura actual

```text
Clase 1/
  Codigo/
  Slides/
Clase 2/
  Codigo/
  Slides/
Tareas/
Entregas/
```

## Rol de cada carpeta

- `Clase N/`: material teorico y practico provisto o trabajado durante la clase. Sirve como base principal para resolver tareas y entregas.
- `Clase N/Codigo/`: notebooks de clase, ejercicios, ejemplos practicos y resumentes tecnicos.
- `Clase N/Slides/`: PDFs o material teorico de la clase.
- `Tareas/`: consignas, notebooks base o ejercicios a resolver.
- `Entregas/`: versiones finales preparadas para entregar.
- `.openspec/`: especificaciones, planes y seguimiento del trabajo con Codex.

## Tipo de trabajo esperado

El repositorio probablemente combine:

- notebooks Jupyter (`.ipynb`);
- PDFs de clase;
- analisis exploratorio;
- feature engineering temporal;
- validacion temporal;
- modelos baseline y modelos de forecasting;
- informes o entregables academicos.

Los notebooks deben poder abrirse y ejecutarse en Google Colab siempre que las dependencias y datos esten disponibles.

## Principio de trabajo

Antes de modificar una tarea o entrega, Codex debe entender:

1. cual es la consigna;
2. que material teorico y practico de las carpetas `Clase N/` aplica;
3. que notebook o archivo es fuente;
4. que archivo debe ser la entrega final;
5. como verificar que el resultado es reproducible en Google Colab.

## Uso de materiales de clase

Las carpetas `Clase N/` son material de referencia central. Antes de resolver una entrega, Codex debe revisar los notebooks, ejercicios y slides relevantes de las clases asociadas al tema.

Ese material debe usarse para:

- identificar la metodologia esperada por la materia;
- reutilizar patrones de resolucion vistos en clase;
- tomar como referencia ejemplos de codigo;
- alinear la explicacion teorica con el enfoque de la catedra;
- justificar decisiones en el notebook y en el README de entrega.

## Entorno principal

- Lenguaje: Python.
- Formato principal: notebooks `.ipynb`.
- Plataforma objetivo: Google Colab.
- Carpeta de consignas: `Tareas/`.
- Carpeta de entregas: `Entregas/`.
